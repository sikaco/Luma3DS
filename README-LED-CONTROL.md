# Luma3DS LED Control fork overlay

Base tested against upstream commit `aef31308a7ea33601d9d21cdede1dfd8471c07b0`.

## Features

- Rosalina -> System configuration -> LED control
- Power/Wi-Fi shared awake brightness (0-100%)
- Sleep Power LED modes:
  - Stock breathing (MCU-fixed brightness)
  - Dim static (uses configurable shared LED brightness)
  - Off
- Separate configured shared brightness while asleep for Wi-Fi / Dim static Power mode
- Low-battery policy:
  - Custom (default)
  - System default
  - Disabled
- Default custom thresholds:
  - 1.5%: solid red
  - 1.2%: blinking red
- 0.3% hysteresis and 2-second debounce
- Battery polling suspended during full sleep
- PTM/MCU notifications at 10%, 5%, charger insert/remove request an immediate refresh
- Configuration stored in `/luma/led_config.bin`
- Orange charging LED remains stock: no safe independent brightness interface is known

## Important hardware limitation

The stock blue sleep breathing mode is generated by the MCU. Power LED mode 2 ignores the shared LED brightness register, so its breathing amplitude cannot be safely dimmed using the documented MCU interface. Use **Dim static** for a truly dim sleep Power LED.

## Build

The included GitHub Actions workflow uses `devkitpro/devkitarm:latest`, installs `firmtool` when needed, applies the overlay, builds Luma3DS, and uploads `boot.firm` plus its SHA-256 hash.
